# Варианты сборки

Девять скриптов в `package.json`, но набирать руками нужно только четыре —
остальные это промежуточные звенья, которые вызываются изнутри.

## Точки входа

| Команда | Что делает |
|---|---|
| `npm run dev` | Локальная разработка на моках (`--mode mock`). Единственный способ поднять фронт у себя: против живого API браузер упрётся в CORS |
| `npm run deploy` | Релиз веба целиком: собирает оба бандла и заливает по FTP |
| `npm run cap:sync` | Android-бандл на прод-API, обфусцированный, + `cap sync` |
| `npm run cap:sync:dev` | То же, но на staging-API. Это то, что уходит тестировщикам |
| `npm run cap:sync:staging` | Отладочный Android-бандл: staging-API, без обфускации и терсера |

## Внутренние звенья

Отдельно вызывать не нужно.

| Команда | Кем вызывается |
|---|---|
| `build` | `deploy` — виджет кабинета, IIFE в `dist/` |
| `build:public` | `deploy` — публичный бандл в `dist/shared/` |
| `build:capacitor` | `cap:sync` и `cap:sync:dev` |
| `build:capacitor:staging` | `cap:sync:staging` |
